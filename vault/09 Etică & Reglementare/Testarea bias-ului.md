# Testarea bias-ului

## Riscuri
Precizia tracking-ului și a modelelor poate varia după:
- tonul pielii (important pentru [[rPPG - fotopletismografie la distanță|rPPG]])
- vârstă (copii, vârstnici — riduri, [[Hipomimie|hipomimie]])
- gen, barbă, machiaj, ochelari, acoperăminte
- afecțiuni faciale (tocmai populația-țintă!)
- lumină, cameră, unghi

## Protocol propus
1. Set de test stratificat (cu consimțământ) sau subseturi ale datelor publice ([[MOC Date și Modele]]).
2. Metrici per subgrup: rata de detecție, eroarea landmarks, eroarea metricilor derivate.
3. Praguri de acceptare definite **înainte** de test.
4. Raport publicat intern în [[MOC Experimente]].
